About

I've spent more than six years in software quality, across e-commerce, social media and regulated gaming platforms. These days I mostly build Python test automation: UI tests with Selenium and Pytest, API suites driven by OpenAPI specs, and CI pipelines that run them all on every change. Lately I've been using AI tools like Claude Code to draft tests faster, and working out where a human still has to check.

I studied computer science at NTU after a diploma in electrical and electronic engineering at Singapore Polytechnic, and started out in database support before moving into testing. I speak English, Chinese and Malay.

Outside work I plan trips down to the last bus connection (and track every dollar), and I've been playing, and logging, Nintendo Switch games since 2018.
